## yamll explain

Explains why a generated YAML path has its final value

### Synopsis

Explains the final value of a generated YAML path, including its origin and any imported or merged values it overrides.

```
yamll explain [flags] <file:path|path>
```

### Examples

```
yamll explain internal/fixtures/import.yaml:base.movies
yamll explain --file internal/fixtures/import.yaml base.movies
```
